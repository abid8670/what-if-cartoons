# What If Theory — AI-Animated Sci-Fi "What If" Shorts

A YouTube channel exploring impossible scenarios, alternate realities, and "what if" questions that bend the laws of physics, space, and time.

Every episode asks one question: **What if the rules were different?** From seeing the future to pausing time, from doubled gravity to hearing every sound on Earth — each video takes one real, verified fact and spins it into a mind-bending 15-25 second scenario.

## 📋 Content Plan
Each episode:
- **Cold open:** 3 quick demos of the premise
- **Title card:** The "What If" question
- **The fun:** exploring the scenario
- **The turn:** one real, verified fact that flips the premise
- **End:** clean cut, no outro (Shorts format)

## 🛠️ Development Setup
This project uses a free AI animation pipeline. See the [free setup guide](https://www.freshstack.ai/resources/free-ai-animation) for details.

### Quick start
```powershell
cd D:\AI-Cartoons
opencode run --dir "D:\AI-Cartoons" --command what-if --model "opencode/glm-5.3-flash-free" --variant high --auto "What if <your idea>?"
```

### Project structure
```

├── .claude/skills/what-if-animation/   # animation skill (cloned)
```
